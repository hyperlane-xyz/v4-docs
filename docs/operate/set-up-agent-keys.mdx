Validators sign checkpoints and storage announcements. Relayers sign transactions to deliver messages. For production signing, we strongly recommend using a key held in a hardware security module (HSM) outside the agent process.

<a id="2-aws-kms"></a>

## Production signing

Validators support two HSM-backed KMS options.

1. [AWS KMS](/docs/operate/aws-kms) is the default choice in the Validator guide.
2. [Google Cloud KMS](/docs/operate/google-cloud-kms) is also supported for Validator checkpoint signing.

Relayers can use [AWS KMS](/docs/operate/aws-kms) for transaction signing. Google Cloud KMS is also available for EVM and Tron transaction signers. [Signer configuration](/docs/operate/config/config-reference#defaultsignertype)

Choose the signing provider independently of the bucket where the Validator publishes its signed checkpoints. See [checkpoint storage](/docs/operate/validators/run-validators#checkpoint-syncer-configuration).

<a id="1-hexadecimal-keys"></a>

## Hexadecimal keys for local development

Use a dedicated hexadecimal key for local development. The agent loads the private key into memory.

### Generate a hexadecimal key

Keep track of your address and private key for use with your agent. Do not lose or leak it.

<Tabs>
  <Tab title="Cast CLI">
    Using [Foundry's cast](https://book.getfoundry.sh/cast/), you can create a new key pair:

    ```sh
    cast wallet new
    ```

    The output will look something like this:

    ```
    Successfully created new keypair.
    Address: 0x32e6d32E7b1C8691Ef4ad3841003371214a0eebC
    Private Key: 0x2958f0eb2ab71bbfb5ea1422835e20e488778b61e3c107f369572e2b53b578f9
    ```

  </Tab>
  <Tab title="Using privatekeys.pw">
    You can visit [https://privatekeys.pw/keys/ethereum/random](https://privatekeys.pw/keys/ethereum/random), which will automatically display a list of hexadecimal private keys and their addresses.

    <Warning>
    Please note that because these are generated by a website, these private keys should be considered insecure and should not be used for anything other than testing purposes!
    </Warning>

  </Tab>
</Tabs>
